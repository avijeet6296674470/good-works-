## 4. Accessibility

- **Decorative icons are hidden from assistive technology.** Most icons are decorative.
- An icon carrying meaning gets an accessible label. An icon-only button always does.
- **An icon alone is not a label** for anything a user could get wrong. Pair it with text wherever the action is destructive, unusual or ambiguous.
